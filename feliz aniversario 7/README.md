# Carta de aniversario 💌

Página web con desbloqueo por huella, sobre animado y carta con pétalos.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (público), por ejemplo `carta`.
2. Sube estos archivos a la raíz del repositorio: `index.html`, `.nojekyll` y `README.md`.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda.
5. Espera 1 o 2 minutos. Tu página quedará en:
   `https://TU-USUARIO.github.io/carta/`

## Editar el texto

Abre `index.html` y cambia el bloque `CONFIG` al inicio del script
(título, saludo, párrafos y firma). Guarda los cambios (commit) y la página se actualiza sola.
